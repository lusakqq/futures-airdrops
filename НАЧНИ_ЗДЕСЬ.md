# Начни здесь

Всё по фьючерсам и аирдропам лежит в этой папке:

| Что | Где |
|---|---|
| Обучение (6 вопросов) | `1_ОБУЧЕНИЕ.md` |
| Бот оповещений об аирдропах | `2_bot_airdrops/` |
| Бот для шорта на Bitget | `3_bot_futures/` |

## Что нужно сделать тебе (по порядку)

1. **Прочитать** `1_ОБУЧЕНИЕ.md` (минут 15).
2. **Установить Python 3.10+** с python.org (галочка «Add Python to PATH»).
3. **Бот аирдропов:**
   - в Telegram у @BotFather: `/newbot`, получить токен;
   - добавить бота админом в свой канал (право публиковать);
   - узнать ID канала через @userinfobot (переслать ему пост из канала);
   - в папке `2_bot_airdrops`: `pip install -r requirements.txt`, скопировать `.env.example` в `.env`, вписать токен, ID и часовой пояс;
   - проверить `python airdrop_bot.py --dry --once`, затем `python airdrop_bot.py --test`, затем запустить `python airdrop_bot.py`.
4. **Bitget:**
   - включить Демо-торговлю, создать **демо** API-ключ (только фьючерсы, **без вывода**), записать Key, Secret, Passphrase;
   - в папке `3_bot_futures`: `pip install -r requirements.txt`, `.env.example` → `.env`, вписать ключи.
5. **Проверка торгового бота:**
   - `MODE=dry`, `python short_bot.py BTC/USDT`: бот только покажет ордер;
   - `MODE=demo`, то же самое: откроет шорт на демо-счёте. Проверь в приложении, что стоп виден, закрой вручную;
   - 10-20 сделок на демо, записывай результаты.
6. **Только потом реальные деньги:** новый ключ (без вывода, с привязкой к IP), перевести на фьючерсный счёт только сумму под сделку, `MODE=live`.

## Самое важное

- **Плечо 2-3х**, на сделку **$10-20 маржи**, не весь депозит.
- **Изолированная маржа** и **стоп-лосс сразу** (бот делает это сам, стоп по умолчанию +15%).
- Листинг может пойти **вверх** (сквиз). Стоп в резком движении исполняется хуже указанной цены.
- Фьючерсы часто открываются **не одновременно** со спотом. Время смотри в анонсе Bitget.
- Новые контракты: высокий funding и ограничения по плечу.
- API-ключ **никогда с правом вывода**. Файл `.env` никому не показывай.
- Аирдропы в API CoinMarketCap и CryptoRank платные, поэтому бот берёт **официальные анонсы Bitget** (бесплатно).
- Боты проверены тестами, но на живой бирже и в Telegram не запускались. Поэтому идём строго dry → demo → live.
