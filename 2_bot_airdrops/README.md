# Бот №1: оповещения об аирдропах и клейме в Telegram-канал

Раз в 10 минут бот читает официальные анонсы Bitget и пропускает **только** те,
где речь об аирдропе, клейме или раздаче токена (Airdrop, Claim, Token Distribution, HODLer).
Конкурсы, торговые акции, розыгрыши, делистинги и обычные новости отбрасываются.

Каждый пост содержит:
- имя токена;
- дату и время раздачи, переведённые в ваш часовой пояс (бот ищет время в тексте анонса);
- ссылку на официальный анонс;
- картинку: логотип монеты с CoinGecko на фирменной карточке с датой. Если логотип не найден, карточка без логотипа.

## Про источники честно

| Источник | Цена | Что даёт |
|---|---|---|
| **Анонсы Bitget** (официальный API биржи) | бесплатно, ключ не нужен | Основной источник. Для вашей стратегии он самый полезный: там точное время раздачи и старта торгов на Bitget |
| CoinMarketCap Airdrops API | только платный тариф (Startup и выше, от ~$79 в месяц) | Включается, если вписать `CMC_API_KEY`. На бесплатном ключе CMC этот раздел недоступен |
| CryptoRank API | аирдропы и разлоки только на тарифе Advanced (~$149 в месяц) | В бота не добавлен: для бюджета $200 это слишком дорого |

Если в анонсе нет точного времени, бот так и пишет: «не указаны в анонсе, смотрите по ссылке».
Он не выдумывает время.

## 1. Создаём бота в @BotFather

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите **Start**.
2. Отправьте `/newbot`.
3. Введите имя бота, например `My Airdrop Alerts`.
4. Введите username, он должен заканчиваться на `bot`, например `my_airdrop_alerts_bot`.
5. BotFather пришлёт **токен** вида `1234567890:AAH...`. Это пароль бота, никому его не показывайте.
   Вставьте его в `.env` в строку `TELEGRAM_BOT_TOKEN=`.

## 2. Подключаем бота к приватному каналу

1. Откройте свой канал → **Управление каналом** → **Администраторы** → **Добавить администратора**.
2. Найдите своего бота по username и дайте право **Публиковать сообщения**.

## 3. Узнаём ID канала

Самый простой способ:
1. Опубликуйте в канале любое сообщение.
2. Перешлите это сообщение боту **@userinfobot** (или **@getmyid_bot**).
3. Он ответит ID канала вида `-1001234567890`. Вставьте его в `.env` в строку `TELEGRAM_CHANNEL_ID=`.

Способ без сторонних ботов: после шага 2 опубликуйте сообщение в канале и откройте в браузере
`https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`. Найдите `"chat":{"id":-100...`.

## 4. Установка и запуск

1. Установите Python 3.10+ с https://www.python.org/downloads/ (галочка **Add Python to PATH**).
2. Откройте командную строку в папке `2_bot_airdrops` и выполните:
   ```
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env`, впишите токен, ID канала и часовой пояс (`TIMEZONE`).
4. Проверка без отправки (посты печатаются в консоль):
   ```
   python airdrop_bot.py --dry --once
   ```
5. Пробный пост в канал (проверяет токен, права и ID канала):
   ```
   python airdrop_bot.py --test
   ```
6. Обычная работа:
   ```
   python airdrop_bot.py
   ```
   Окно не закрывайте: бот работает, пока оно открыто. Остановить: `Ctrl+C`.

Чтобы бот работал круглосуточно без вашего компьютера, его можно запустить на дешёвом VPS (от $3-5 в месяц).

## Тонкая настройка

- `INCLUDE_REGEX` и `EXCLUDE_REGEX` в `.env` меняют слова фильтра (по умолчанию уже настроены).
- Файл `sent.json` хранит уже отправленные анонсы, чтобы не было повторов. Удалите его, если хотите начать заново.

## Что проверено

Разбор дат, фильтр, перевод времени и картинка проверены на тестовых анонсах.
Живой запрос к API Bitget и отправка в Telegram у меня не проверялись (из моей среды нет доступа к этим сайтам),
поэтому первый запуск сделайте с `--dry --once`, а затем `--test`.
